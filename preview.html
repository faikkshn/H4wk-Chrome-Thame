📦 Kurulum

Depoyu İndirin

GitHub deposundan projeyi klonlayın:

git clone https://github.com/faikkshn/H4wk-Chrome-Thame.git

PNG İkonları Oluşturun

SVG dosyalarını 16x16, 48x48 ve 128x128 boyutlarında PNG'ye dönüştürün.

Online araçlar: CloudConvert, Convertio veya benzeri bir araç kullanabilirsiniz.

Chrome Extensions Sayfasını Açın

Chrome'da chrome://extensions/ adresine gidin.

Developer Mode'u Aktifleştirin

Sağ üst köşedeki "Geliştirici modu" (Developer mode) seçeneğini açın.

Temayı Yükleyin

"Paketlenmemiş öğe yükle" butonuna tıklayın ve proje klasörünü seçin.
