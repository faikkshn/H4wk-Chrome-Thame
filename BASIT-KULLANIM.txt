┌──────────────────────────────────────────────────────────────────┐
│  ADIM 1: EXTENSION'I YÜKLE                                       │
└──────────────────────────────────────────────────────────────────┘

1. Chrome aç
2. Adres çubuğuna yaz:  chrome://extensions/
3. SAĞ ÜST köşede "Developer mode" açık yap
4. Sol üstte "Load unpacked" tıkla
5. H4wk-Chrome-Thame klasörünü seç
6. TAMAM!

┌──────────────────────────────────────────────────────────────────┐
│  4 SEKME NEDİR?                                                  │
└──────────────────────────────────────────────────────────────────┘

1. TOOLS       → JSON, Color Picker, Screenshot, vb.
2. ENCODING    → Base64, URL, Hex encode/decode
3. SECURITY    → Hash, Cookies, Headers
4. PAGE INFO   → URL, Links, Images bilgileri


┌──────────────────────────────────────────────────────────────────┐
│  ÖRNEK: JSON FORMATLA                                            │
└──────────────────────────────────────────────────────────────────┘

1. api.github.com adresine git
2. Sağ üstte H4WK ikonuna tıkla
3. "JSON Format" butonuna tıkla
4. TAMAM! JSON formatlanır!


┌──────────────────────────────────────────────────────────────────┐
│  ÖRNEK: BASE64 ENCODE                                            │
└──────────────────────────────────────────────────────────────────┘

1. H4WK ikonuna tıkla
2. "ENCODING" sekmesine tıkla
3. Kutuya "hello world" yaz
4. "Base64 Encode" butonuna tıkla
5. Altta sonucu gör: aGVsbG8gd29ybGQ=
6. "Copy" butonuna tıkla


┌──────────────────────────────────────────────────────────────────┐
│  ÖRNEK: HASH HESAPLA                                             │
└──────────────────────────────────────────────────────────────────┘

1. H4WK ikonuna tıkla
2. "SECURITY" sekmesine tıkla
3. Kutuya "password123" yaz
4. "SHA-256" butonuna tıkla
5. Hash görünür!


┌──────────────────────────────────────────────────────────────────┐
│  HIZLI ERİŞİM: KLAVYE                                           │
└──────────────────────────────────────────────────────────────────┘

Mouse kullanmadan:

    Ctrl + Shift + H    →  Popup'ı aç

    Alt + J             →  Sayfadaki JSON'u formatla

    Alt + C             →  URL'i kopyala


┌──────────────────────────────────────────────────────────────────┐
│  HIZLI ERİŞİM: SAĞ TIK                                          │
└──────────────────────────────────────────────────────────────────┘

1. Herhangi bir metni FARE ile SEÇ
2. SAĞ TIK
3. "H4WK Toolkit" görürsün
4. Alt menülerden birini seç:
   - Encode/Decode → Base64 Encode
   - Encode/Decode → URL Encode
   - Hash → SHA-256
   - Save to Quick Notes
   - Search on GitHub


┌──────────────────────────────────────────────────────────────────┐
│  CONSOLE'DA KULLAN                                               │
└──────────────────────────────────────────────────────────────────┘

1. Herhangi bir sayfada F12 bas
2. "Console" sekmesine git
3. Yaz ve Enter bas:

    H4WK.showBanner()

4. Diğer komutlar:

    H4WK.extractLinks()      → Tüm linkleri göster
    H4WK.extractImages()     → Tüm görselleri göster
    H4WK.getMetadata()       → Sayfa bilgileri
    H4WK.darkMode()          → Dark mode aç/kapa
